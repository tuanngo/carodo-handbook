# Reference screens

Screenshots of other apps, kept for design reference only. **Never committed**: the images are
ignored by `.gitignore`, only this README is tracked. They may show accounts, places or routes, so
they never leave this machine and are never copied into `carodo-ios`.

Layout: one folder per app, files named by flow and order.

```
screens/
  <app>/               e.g. carstack/, strava/, apple-maps/
    01-home.png
    02-record-start.png
    03-record-live.png
    ...
```

A finding worth keeping goes into a spec draft or `design/` as words (what works, why), not as a
copied screen.
