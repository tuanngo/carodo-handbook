# Drafts

Specs and designs for features that have no code yet. Use the spec template in
[`carodo-ios/docs/specs/README.md`](../../carodo-ios/docs/specs/README.md#template). The change that
adds a feature's first code moves its draft to `carodo-ios/docs/specs/<feature>.md`; delete it
here in the same step.

| Draft | Feature |
|---|---|
| [`achievements.md`](achievements.md) (Ready) | Road Miles and Faithful Car in tiers from the device's history; no points or levels; a bundled catalogue, served later |
| [`badge-ledger.md`](badge-ledger.md) (Approved) | Badge unlock ledger and instance state, per-field merge rules for iCloud, explicit publishing through the outbox, contract and D1 changes, vehicle archive |
| [`passport-v2.md`](passport-v2.md) (Draft) | Driving Passport V2: identity, Footprint, Places Visited, highlights and milestones on one achievement engine, Rhythm strip, Garage preview; four slices |
| [`weather.md`](weather.md) (Draft) | Weather on a drive: looked up after saving (start, end, hourly) with WeatherKit, shown on the detail page and the share card; blocked on the paid developer account |
